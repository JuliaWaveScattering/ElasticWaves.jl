Elastic media and waves

ElasticWaves.ConstantRollerSpeedMethod — Type
ConstantRollerSpeedMethod(; loading_modes = Int[], ratio_shear_to_normal = 0.0, modal_method, tol)

A prior method which assumes that the rollers move at a constant angular speed, and that the boundary data is due to an unknown loading profile on the rollers. The Fourier modes of the loading profile to solve for are given by loading_modes, and several frequencies are solved together with ElasticWaveVector. See also PriorMethod.

ElasticWaves.ModalMethod — Type
ModalMethod(; tol = sqrt(eps(Float64)), only_stable_modes = true, maximum_mode = 160, modes = Int[])

Solve for the waves in a RollerBearing one Fourier mode at a time. For each mode the two boundary conditions of a BearingSimulation lead to a 4 x 4 linear system for the coefficients of the pressure and shear potentials.

A mode is considered unstable when its estimated relative error is larger than tol. If only_stable_modes = true, the modes are solved in order of increasing abs(mode) until the first unstable mode is found, and then that mode and all higher modes are discarded. If only_stable_modes = false, all modes are kept, which can lead to very large errors.

If modes is empty, the modes are determined from the boundary data, keeping only abs(mode) < maximum_mode.

After solving with ElasticWave(::BearingSimulation), the method stored in the wave holds the modes that were kept and the estimated error of each in mode_errors.

ElasticWaves.PriorMethod — Type
PriorMethod(; tol = sqrt(eps(Float64)), modes = Int[], modal_method = ModalMethod(tol = tol, modes = modes))

Solve for the waves in a RollerBearing by using prior knowledge about the boundary data. The prior is given as a BoundaryBasis when defining the BearingSimulation: the data on that boundary is assumed to be a linear combination of the elements of the basis, and the coefficients of this combination are fitted to the fields of the measured boundary data.

This is typically used to solve inverse problems where there are only a few measurements. For example, to predict the traction on the inner boundary from a few sensors placed on the outer boundary.

The Fourier modes used, and the tolerance for which of them are stable, are given by modal_method, see ModalMethod.

After solving with ElasticWave(::BearingSimulation), the method stored in the wave holds the condition_number of the system which was solved, and the relative error boundary_error of the fit to the measured data.

ElasticWaves.Elastic — Type
Elastic(Dim::Integer; ρ, cp, cs)
Elastic(Dim::Integer; ρ, λ, μ)

Physical properties of a homogeneous isotropic elastic medium in Dim spatial dimensions, with density ρ, pressure wavespeed cp, and shear wavespeed cs. The wavespeeds can be complex to model attenuation.

Instead of the wavespeeds, the Lamé parameters λ and μ can be given, in which case cp = sqrt((λ + 2μ) / ρ) and cs = sqrt(μ / ρ).

Simulations in this medium produce vector fields with Dim components. For Dim = 3 we use the Debye potentials to describe the fields.

Examples

steel = Elastic(2; ρ = 7800.0, cp = 5000.0, cs = 3500.0)

ElasticWaves.ElasticWave — Type
ElasticWave{Dim,T}

A type to store an elastic wave expanded in some modal basis. The only basis used in this package is a regular radial expansion, which is needed for scattering and waves within a sphere or cylinder.

For Dim = 3 the field potentials are, in order, the φ pressure, Φ shear, and χ shear, where Φ and χ are the Debye potentials such that the displacement is given by: u = ∇φ + ∇x∇x(Φ .* r) + ∇x∇x∇x(χ .* r) ./ kS, where kS is the shear wavenumber and r is a vector pointing in the radial direction, that is r = (x,y,z) in Cartesian coordinates.

MultipleScattering.regular_basis_function — Method
regular_basis_function(medium::Elastic{3}, ω, field_type::FieldType = DisplacementType())

Returns a function (order, x) -> basis which gives the regular spherical waves, up to the basis order, evaluated at the point x.

The basis is a matrix with three rows, one for each Cartesian component of the field given by field_type. The columns are ordered by the spherical harmonics, and for each spherical harmonic there are three columns: first for the pressure potential φ, and then for the two shear Debye potentials Φ and χ. If coefficients is a vector with the coefficients of a regular wave in this same order, then the field at x is basis * coefficients.

See also outgoing_basis_function.

Roller bearings

Types and functions to describe a roller bearing and the data on its boundaries.

ElasticWaves.BearingSimulation — Type
BearingSimulation(ω, bearing::RollerBearing, boundarydata1::BoundaryData, boundarydata2::BoundaryData; method = ModalMethod(), nondimensionalise = true, kws...)
BearingSimulation(ω, method, bearing, boundarydata1, boundarydata2; kws...)

Holds everything needed to calculate the elastic waves with angular frequency ω in a RollerBearing. Two BoundaryData are needed, and these can be on the same boundary. For example, giving the traction on both the inner and outer boundary is a forward problem, whereas giving both the traction and the displacement on the outer boundary can be used to predict the traction on the inner boundary.

The method is either a ModalMethod or a PriorMethod. The PriorMethod needs a BoundaryBasis for one of the boundaries, given by the keyword boundarybasis1 or boundarybasis2.

To solve the simulation use ElasticWave(::BearingSimulation).

Examples

steel = Elastic(2; ρ = 7800.0, cp = 5000.0, cs = 3500.0)
bearing = RollerBearing(medium = steel, inner_radius = 1.0, outer_radius = 2.0)

θs = LinRange(0, 2pi, 41)[1:end-1]
pressure = exp.(-20 .* (θs .- pi) .^ 2)
shear = zeros(length(θs))

bd1 = BoundaryData(TractionBoundary(inner = true); θs = θs, fields = hcat(pressure, shear))
bd2 = BoundaryData(TractionBoundary(outer = true); θs = θs, fields = zeros(length(θs), 2))

sim = BearingSimulation(4e4, bearing, bd1, bd2; method = ModalMethod())
wave = ElasticWave(sim)

ElasticWaves.BoundaryData — Type
BoundaryData(boundarytype::BoundaryCondition; θs = [], fields = [], coefficients = [], modes = [])

Gives all the information on one boundary of a RollerBearing. You can specify the forcing either by giving the Fourier coefficients, or by specifying the fields. The fields represent either the displacement or traction when varying the polar angle θs.

Both fields and coefficients are matrices with two columns. The first column is the radial component, and the second column is the angular component, of the displacement or traction.

The relationship between the fields and the coefficients is given by $f_{j}(\theta) = \sum_m \text{mode}_{mj} e^{i \theta m}$, where $f$ represents the fields. To calculate the fields from the coefficients we can use:

exps = [
    exp(im * θ * m)
for θ in θs, m = modes];

fields = exps * coefficients

If the coefficients were specified, then they will be used directly. If the coefficients were not given, then fields will be used to calculate the coefficients: coefficients = exps \ fields.

ElasticWaves.RollerBearing — Type
RollerBearing(; medium::Elastic{2}, inner_radius, outer_radius, number_of_rollers = 8, rollers_inside = true, angular_speed = 1.0, kws...)

A roller bearing raceway: the region between two concentric circles with radius inner_radius and outer_radius, filled with the elastic medium.

The rollers are in contact with the inner boundary of the raceway if rollers_inside = true, and otherwise with the outer boundary. The rollers are equally spaced and move around the raceway with angular_speed. The roller_radius and roller_separation can also be given, but need to be compatible with the number_of_rollers and the geometry of the raceway.

To solve for the elastic waves in the raceway see BearingSimulation.

Examples

steel = Elastic(2; ρ = 7800.0, cp = 5000.0, cs = 3500.0)
bearing = RollerBearing(medium = steel, inner_radius = 1.0, outer_radius = 2.0)

ElasticWaves.point_contact_boundary_data — Method
point_contact_boundary_data(θs::Vector, bearing::RollerBearing, bc::BoundaryCondition{TractionType}, basis_order::Int, friction_coefficient = 1.0)

Returns the BoundaryData for when each roller of the bearing is in contact with the raceway at only one point, and each roller applies a unit force.

The normal traction is then a sum of Dirac deltas, one for each roller, which has the Fourier series $\frac{Z}{2\pi} \sum_n \mathrm e^{\mathrm i n Z \theta}$, where $Z$ is the number of rollers. This sum is truncated to $|n| \leq$ basis_order, so the modes of the boundary data returned go from -basis_order * Z to basis_order * Z. The shear traction is the friction_coefficient multiplied by the normal traction.

ElasticWaves.ElasticWave — Method
ElasticWave(sim::BearingSimulation)

Solves the BearingSimulation and returns the ElasticWave in the raceway of the bearing. The method used to solve is given by sim.method.

The field potentials of the wave returned holds first the pressure and then the shear HelmholtzPotential. The field method holds information on how accurate the solution is, see ModalMethod and PriorMethod.

Scattering from spheres

ElasticWaves.plane_z_shear_source — Method
plane_z_shear_source(medium::Elastic{3,T}, pos::AbstractArray{T} = zeros(T,3), amplitude::Union{T,Complex{T}} = one(T))

Creates an incident plane shear wave which propagates along the z-axis and is polarised along the x-axis. That is, the displacement has the form $A e^{i k_s (z - z_0)} (1,0,0)$, where $A$ is the amplitude, $k_s$ is the shear wavenumber, and $z_0$ is the last component of pos. The coefficients of the Debye potentials which correspond to this plane wave are given in "Resonance theory of elastic waves ultrasonically scattered from an elastic sphere - 1987".

ElasticWaves.t_matrix_pressure_scaled — Method
t_matrix_pressure_scaled(Particle{3,Elastic{3,T},Sphere{T,3}}, Elastic{3,T}, ω, order)

The part of the T-matrix, for a 3D spherical elastic particle in a 3D elastic medium, which is needed for an incident pressure wave. Returns (Tpp, Tsp), where Tpp[l+1] gives how the pressure potential φ of degree l scatters into φ, and Tsp[l+1] gives how φ scatters into the shear potential Φ, for l = 0:order. These are the first two elements of the first column of the block of t_matrix for the degree l, except that Tsp is multiplied by exp(im * ks * a), where ks = ω / outer_medium.cs and a is the radius of the particle.

Use this function when the shear wave in the outer medium decays quickly, such as in a viscous liquid, which is an elastic medium with the complex shear wave speed cs = sqrt(-im * ω * ν) for a kinematic viscosity ν. In this case Tsp grows like exp(imag(ks) * a), and the spherical Hankel functions of the shear wave decay like exp(-imag(ks) * a), so that t_matrix can not be calculated when imag(ks) * a is larger than about 700. Here the scattered shear wave is written in terms of hankelh1x, which is the Hankel function multiplied by exp(-im * ks * a), and that is the same as solving for Tsp * exp(im * ks * a). There is no approximation, and no term is exponentially large or small.

ElasticWaves.t_matrix_shear_scaled — Method
t_matrix_shear_scaled(Particle{3,Elastic{3,T},Sphere{T,3}}, Elastic{3,T}, ω, order)

The part of the T-matrix, for a 3D spherical elastic particle in a 3D elastic medium, which is needed for an incident shear wave given by the potential Φ. Returns (Tps, Tss), where Tps[l+1] gives how the shear potential Φ of degree l scatters into the pressure potential φ, and Tss[l+1] gives how Φ scatters into Φ, for l = 0:order. These are the first two elements of the second column of the block of t_matrix for the degree l, except that Tps is multiplied by exp(im * ks * a), and Tss is multiplied by exp(2im * ks * a), where ks = ω / outer_medium.cs and a is the radius of the particle. There are no shear waves for l = 0, so the first element of both is zero.

Like t_matrix_pressure_scaled, use this function when the shear wave in the outer medium decays quickly, such as in a viscous liquid. In this case the incident shear wave grows like exp(imag(ks) * a) towards the surface of the particle, so that Tps grows like exp(imag(ks) * a), and Tss grows like exp(2 * imag(ks) * a). Here the incident shear wave is written in terms of besseljx, and the scattered shear wave in terms of hankelh1x, which is the same as solving for the scaled Tps and Tss. There is no approximation, and no term is exponentially large or small.

The T-matrix is reciprocal, which implies that Tps[l+1] = l * (l+1) * (kp / ks) * Tsp[l+1], where kp = ω / outer_medium.cp and Tsp is given by t_matrix_pressure_scaled.

MultipleScattering.t_matrix — Method
t_matrix(Particle{3,Elastic{3,T},Sphere{T,3}}, Elastic{3,T}, ω, order)

The T-matrix for a 3D spherical elastic particle in a 3D elastic medium. This t-matrix T has the diagonal matrices of the form T = diag(T1,T2,...). Let gn = [gφn; gΦn; gχn] be the coefficients of a regular spherical expansion for the pressure potential φ, and two Debye potentials Φ and χ. See ElasticSphereScattering.pdf for details. Multiply the matrix with the regular coefficients Tn * gn returns the scattering coefficients for the potentials.
